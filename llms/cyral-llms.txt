# Cyral

> Cyral is a data security and governance platform (founded 2018, Milpitas CA; acquired by Varonis in March 2025) providing an agentless, stateless data-layer sidecar that monitors and governs access to data repositories such as Snowflake, PostgreSQL, MySQL, MongoDB, Amazon S3, Kafka, and Oracle. Built API-first, its Control Plane exposes a REST API (OAuth2 client-credentials) automatable through the official Cyral Terraform provider. After the Varonis acquisition, cyral.com redirects to Varonis' Database Activity Monitoring product; first-party tooling remains on the cyralinc GitHub organization and the Terraform Registry.

## Note
- Company status: acquired by Varonis Systems (announced 2025-03-17). cyral.com now redirects to Varonis DAM. This profile captures the surviving public first-party developer surface.

## API
- Cyral Control Plane API: OAuth2 client-credentials; token endpoint `https://<control-plane-host>:8000/v1/users/oidc/token`; Bearer JWT for subsequent calls. Host is customer/self-hosted (no single public base host).
